# Architecture Decision Records

ADR ghi lại quyết định kiến trúc có ảnh hưởng dài hạn. Tên file dùng `NNNN-short-title.md` và trạng thái `Proposed`, `Accepted`, `Superseded` hoặc `Rejected`.

Mỗi ADR gồm: Context, Decision, Consequences và Alternatives. ADR đầu tiên được tạo khi implementation cần thay đổi một quyết định đã khóa trong tài liệu kiến trúc hiện tại.
