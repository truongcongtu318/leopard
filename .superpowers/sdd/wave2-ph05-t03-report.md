- `POST /auth/refresh { refreshToken }` returning a new `AuthSession`.

- Opaque 256-bit refresh tokens.
- Argon2id refresh token verifier stored with HMAC lookup prefix and session-family metadata.
- Transactional refresh rotation where the previous session is revoked and a replacement session is created atomically.
- Old-token replay revokes the matching session family only.
